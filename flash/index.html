一键烧录

当前浏览器不支持网页烧录。请换用 Chrome 或 Edge（Safari / Firefox 不支持 Web Serial API）。 当前不是 HTTPS / localhost 访问，浏览器已禁用烧录功能。 通过局域网 IP（如 http://192.168.x.x）打开会出现此提示，请改用 https 地址或 localhost。

固件 v1.0.2（3.4 MB，含 bootloader + 应用 + 字库）。烧录约 30–60 秒，期间不要拔线。

操作步骤

  1. 装串口驱动：用 USB 数据线连接设备与电脑，确保已安装 CH340 驱动 或 CP210x 驱动。装好后「设备管理器」里能看到一个 COM 口即正常。
  2. 关掉占用串口的软件：务必先关闭串口助手、Arduino 串口监视器、 以及之前没关的烧录标签页。端口被占用时，浏览器会打开失败、表现为「点了没反应」。
  3. 手动进入下载模式（本板无自动下载电路，必须做）： 按住 BOOT 键不放 → 点一下 EN / RESET 键后松开 → 再松开 BOOT。 若板子只有 BOOT 没有 EN 键：一直按住 BOOT 再插 USB。
  4. 开始烧录：点上方「连接设备并烧录」→ 弹窗里选设备的串口号 → 点「连接」→ 再点「安装」。 进度显示在页面上，出现进度后即可松开 BOOT 键。

失败排查

  • 长时间停在「连接中 / 找不到设备」→ 设备没进下载模式。关闭本标签页释放端口 → 重做第 3 步 → 重新连接。
  • 找不到串口 / 串口列表为空 → 驱动未装好，或数据线是纯充电线（不带数据）。
  • 浏览器一直占用 COM 口 → 关闭本标签页才会释放。
  • 上方自检出现红色 ✗ → 按红字提示处理（换浏览器 / 换 https 地址）。

浏览器支持：Chrome / Edge / Opera（Windows、macOS、Linux、Android 均可用）。 Safari、Firefox 不支持；iOS 因系统限制无串口访问。 本页必须通过 https:// 或 localhost 打开，双击本地 HTML 文件（file://）无法烧录。
